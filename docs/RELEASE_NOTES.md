### Added
- You can now mark a flashcard as known, so you can skip the cards you've already mastered.

- Fixed the score counting so your final score matches the number of answers you got right.

- Fixed typos in the category and top card features so they work as intended.

- Added unit tests for the average score calculation, so future changes are less likely to break it.
- Added documentation explaining how answer checking works, to make the code easier to follow.
